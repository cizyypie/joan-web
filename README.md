Personal portfolio website

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP
- Lucide React
- React Icons

## Features

- Responsive layout for desktop and mobile
- Project showcase section
- Build logs / project progress section
- Smooth scroll-based animations using GSAP
- Reusable content-driven components
- Minimal and clean visual style
- External links to GitHub repositories and live projects
